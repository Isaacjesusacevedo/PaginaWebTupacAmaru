# 🏛️ Página Web Túpac Amaru

Sitio web dedicado a la figura histórica de **Túpac Amaru**, desarrollado con una arquitectura moderna de separación entre frontend y backend. El proyecto está construido con **Vue 3** para la interfaz de usuario y **ASP.NET Core** para la API, ofreciendo una base sólida, escalable y de alto rendimiento.

---

## 📌 Características principales

- **Frontend moderno con Vue 3**: Interfaz de usuario dinámica y responsiva, construida con el framework progresivo Vue.js.
- **Backend con ASP.NET Core**: API robusta y segura que maneja la lógica de negocio y la comunicación con la base de datos.
- **Arquitectura por capas**: El backend está organizado en Controladores, Modelos, DTOs, Servicios y una capa de Datos, siguiendo buenas prácticas de desarrollo.
- **Entorno de desarrollo optimizado**: Utiliza Vite para el frontend, lo que proporciona un entorno de desarrollo rápido y eficiente.
- **Estructura de proyecto profesional**: Incluye un archivo de solución (`brana.sln`) que integra ambos componentes, facilitando la gestión del proyecto.
