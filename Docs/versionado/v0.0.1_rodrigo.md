## Resumen Ejecutido

Proyecto académico minimalista enfocado en **autenticación de administradores** y **exportación a Excel** de listados de estudiantes con información académica. Arquitectura de **capa única** (todo en un proyecto MinimalApiDapper).

### Repository: `AdminRepository.cs` (Dapper)
```csharp
public class AdminRepository
{
    private readonly string _connectionString;

    public async Task<string> LoguearAsync(string usuario, string contrasena)
    {
        using var connection = new SqlConnection(_connectionString);
        var parameters = new DynamicParameters();
        parameters.Add("@Admin_Nom_Usuario", usuario);
        parameters.Add("@Admin_Contra", contrasena);
        parameters.Add("@Mensaje", dbType: DbType.String, size: 100, direction: ParameterDirection.Output);

        await connection.ExecuteAsync("Logueo_Admin", parameters, commandType: CommandType.StoredProcedure);
        return parameters.Get<string>("@Mensaje");
    }

    public async Task<IEnumerable<EstudianteCarreraInfoDto>> ListarEstudiantesCarrerasInfoAcaAsync()
    {
        using var connection = new SqlConnection(_connectionString);
        return await connection.QueryAsync<EstudianteCarreraInfoDto>(
            "sp_Listar_Estudiantes_Carreras_InfAca", commandType: CommandType.StoredProcedure);
    }
}
```

### Service: `AdminService.cs`
```csharp
public async Task<Result<string>> LoguearAsync(string usuario, string contrasena)
{
    var mensaje = await _adminRepository.LoguearAsync(usuario, contrasena);
    if (mensaje.Contains("exitoso", StringComparison.OrdinalIgnoreCase))
        return Result<string>.Ok(mensaje);
    return Result<string>.Fail(mensaje);
}

public async Task<Result<byte[]>> ExportarEstudiantesExcelAsync()
{
    var data = (await _adminRepository.ListarEstudiantesCarrerasInfoAcaAsync()).ToList();
    if (!data.Any()) return Result<byte[]>.Fail("No hay inscripciones hechas.");

    using var workbook = new XLWorkbook();
    var worksheet = workbook.Worksheets.Add("Estudiantes");
    var table = worksheet.Cell(1, 1).InsertTable(data);
    worksheet.Columns().AdjustToContents();

    using var stream = new MemoryStream();
    workbook.SaveAs(stream);
    return Result<byte[]>.Ok(stream.ToArray());
}
```

### Endpoints: `Program.cs`
```csharp
app.MapPost("/api/admin/login", async (LoginRequest data, IAdminService service) =>
{
    var result = await service.LoguearAsync(data.usuario, data.contrasena);
    return result.Success ? Results.Ok(new { mensaje = result.Data })
                          : Results.BadRequest(new { mensaje = result.Error });
});

app.MapGet("/api/admin/exportar-estudiantes", async (IAdminService service) =>
{
    var result = await service.ExportarEstudiantesExcelAsync();
    return result.Success ? Results.File(result.Data!, "application/vnd.openxmlformats-officedocument.spreadsheetml.sheet", "Estudiantes.xlsx")
                          : Results.BadRequest(new { message = result.Error });
});
```

## Stored Procedures Referenciados

| SP | Propósito |
|----|-----------|
| `Logueo_Admin` | Login con parámetros de salida (`@Mensaje`) |
| `sp_Listar_Estudiantes_Carreras_InfAca` | Listado complejo estudiantes + carreras + info académica |

> **Nota:** Los SPs no están en el repo, se asume que existen en la BD `FormularioInscripcionCarreras`.

## Limitaciones / Deuda Técnica v0.0.1

| Problema | Severidad |
|----------|-----------|
| Password en texto plano (`Admin_Contra`) | 🔴 Crítica |
| Sin hash/BCrypt | 🔴 Crítica |
| Connection string hardcodeada en `Program.cs` | 🟠 Alta |
| `Singleton` para Repository (no thread-safe con Dapper) | 🟠 Alta |
| Validación login via `Contains("exitoso")` frágil | 🟡 Media |
| Sin separation of concerns (todo en 1 proyecto) | 🟡 Media |
| Sin tests | 🟡 Media |
| Sin JWT / sesiones | 🟡 Media |
| Solo 2 endpoints | 🟢 Baja |
