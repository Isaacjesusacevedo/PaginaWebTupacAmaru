|-------|-----------|------|

**Todos los endpoints requieren JWT + Policy `AdminPolicy` (roles Admin/SuperAdmin)**
**EXCEPTO:** `POST /api/inscripcion` (público), `GET /health` (público) y **`GET /api/listado` (público)**

| Módulo | Endpoints | Auth |
|--------|-----------|------|
| Health | `GET /health` | Público |
| Listado | `GET /api/listado` (SP académico + prioridad BR) | **Público (AllowAnonymous)** |

| Catálogo Académico | CRUD `/api/inf-academica` | JWT + AdminPolicy |
| Registros por Alumno | CRUD `/api/inf-academica/alumnos` | JWT + AdminPolicy |

## Servicios Académicos (BR Layer)

### `InfAcademicaService` — Catálogo
- CRUD + validación: descripción única, estado HABILITADO/DESHABILITADO
- `DeleteAsync`: bloquea si `InfAcademicaEstRepository.ExistsByInfAcademicaAsync(id)`

### `InfAcademicaEstService` — Registros por Alumno
- `CreateAsync`: valida tipo habilitado, alumno existe, no duplicado (UNIQUE), campos por tipo, estado por defecto
- `UpdateAsync`: **no permite cambiar AlumnoId** (inmutable), revalida todo, usa `ExistsByCombinationAsync(excludeId)`
- `DeleteAsync`: simple

### `InscripcionService` — Inscripción Pública (Flujo Completo)
```csharp
public async Task<ServiceResult<InscripcionResultDto>> InscribirAsync(InscripcionDto dto)
{
    // 1. Valida al menos 1 info académica
    // 2. Para cada item: busca tipo en catálogo, valida habilitado, no repetido en request
    // 3. Valida campos por tipo (InfAcademicaValidator)
    // 4. Crea Alumno (via AlumnoService)
    // 5. Crea N InfAcademicaEst con AlumnoId del creado
    // 6. Transacción implícita: si falla académico → borra alumno (rollback manual)
}
```

### `ListadoService` — Listado Inteligente (NUEVA LÓGICA)
```csharp
// SP devuelve N filas por alumno (1 por registro académico)
var items = await _repository.GetListadoAsync();  // List<ListadoItem>

// BR agrupa y elige 1 fila por alumno:
return items.GroupBy(i => i.AlumnoId)
    .Select(g => g.OrderBy(i => Prioridad(i.TipoAcademico))  // Título=1, Trámite=2, Constancias=3
                  .ThenByDescending(i => i.FechaEmision)     // Más reciente primero
                  .First())
    .Select(CrearDtoConEdadCalculadaEnBR)
    .ToList();
```

## Repositorios: Patrón A vs Patrón B

### Patrón A — Repos Base (ADO.NET Directo)
**Archivos:** `AlumnoRepository`, `AdministradorRepository`, `CarreraRepository`, `ProfesorRepository`, `FormularioRepository`
```csharp
// Create: ExecuteScalarAsync UNA VEZ
// GetById/Exists: FromSqlRaw/SqlQueryRaw + ToListAsync() + FirstOrDefault()
// Update/Delete: ExecuteNonQueryAsync
```

### Patrón B — Repos Académicos (`SpInvoker` Helpers)
**Archivos:** `InfAcademicaRepository`, `InfAcademicaEstRepository`
```csharp
// Usa extension methods de SpInvoker.cs:
_context.QueryEntityAsync<T>("EXEC Sp_Name @Param", params)
_context.ScalarInsertAsync("EXEC Sp_Insert @P1, @P2", params)
_context.NonQueryAsync("EXEC Sp_Update @Id, @P1", params)
_context.ExistsAsync("EXEC Sp_Exists @Id", params)
```

### `SpInvoker.cs` — Helper Centralizado
```csharp
public static class SpInvoker {
    public static async Task<List<T>> QueryEntityAsync<T>(this InstitutoDbContext ctx, string sql, params SqlParameter[] p)
        => await ctx.Set<T>().FromSqlRaw(sql, p).ToListAsync();

    public static async Task<bool> ExistsAsync(this InstitutoDbContext ctx, string sql, params SqlParameter[] p) {
        var rows = await ctx.Database.SqlQueryRaw<int>(sql, p).ToListAsync();
        return rows.Count > 0 && rows[0] == 1;
    }

    public static async Task<int> ScalarInsertAsync(this InstitutoDbContext ctx, string sql, params SqlParameter[] p) { ... }
    public static async Task NonQueryAsync(this InstitutoDbContext ctx, string sql, params SqlParameter[] p)
        => await ctx.Database.ExecuteSqlRawAsync(sql, p);
}
```

## Bugs Conocidos Documentados (`LESSONS_LEARNED.md`)

| Bug | Causa | Estado |
|-----|-------|--------|
| `FirstOrDefaultAsync()` sobre `EXEC` | No composable | ✅ Corregido → `ToListAsync()` + `FirstOrDefault()` |
| `PasswordTemp` no en SP GetById/GetByEmail | EF Core requiere columna mapeada | ⚠️ **Pendiente Alta** |
| Alias `AS Exists` (palabra reservada) | SQL Server warning | ⚠️ Pendiente Media |
| `@FechaInscripcion` redeclarado en SP | DECLARE = param name | ⚠️ Pendiente Baja |
| Doble `ExecuteScalarAsync()` en Create | Copy-paste error | ✅ Corregido (Profesor, Formulario) |
| `QUOTED_IDENTIFIER` en DELETE | Índice UNIQUE filtrado | ✅ Documentado (`-I` flag) |
