# Versión 0.1.0 — Migración N-Tier (Proyecto `instituto`)

> **Proyecto fuente:** `instituto/`
> **Fecha:** 2026-09 (v1.1.0 según PROYECTO.md)
> **Tecnologías:** .NET 9, Minimal API, **EF Core + SPs**, SQL Server, Vue 3 Frontend

---

## Resumen Ejecutivo

Migración completa desde arquitectura monolítica (v0.0.1) a **N-Tier (AD → BR → API)** con:
- Separación en 3 capas backend (`Instituto.AD`, `Instituto.BR`, `Instituto.MinimalAPI`)
- **Entity Framework Core** + Stored Procedures (FromSqlRaw)
- **JWT Authentication** + BCrypt (workFactor: 12)
- **Frontend Vue 3** completo con 19 vistas
- 6 entidades de dominio + 1 DTO (`ListadoItem`)
- ~15 SPs base + tests (44 passing)

## Código Representativo v0.1.0

### DbContext + EF Core (`InstitutoDbContext.cs`)
```csharp
protected override void OnModelCreating(ModelBuilder modelBuilder)
{
    // Administradores - UNIQUE parcial
    entity.HasIndex(e => e.Email).IsUnique().HasFilter("[Activo] = 1");
    
    // Alumnos - UNIQUE DNI + Email
    entity.HasIndex(e => e.Email).IsUnique();
    entity.HasIndex(e => e.DNI).IsUnique();
    
    // FK Alumnos -> Carreras (Restrict)
    entity.HasOne<Carrera>()
          .WithMany()
          .HasForeignKey(a => a.CarreraId)
          .OnDelete(DeleteBehavior.Restrict);
}
```

### Repository Patrón A (ADO.NET Directo)
```csharp
public async Task<Alumno> CreateAsync(Alumno entity)
{
    using var command = connection.CreateCommand();
    command.CommandText = "EXEC sp_Alumnos_Create @Nombre, @Apellido, ...";
    // ... parameters
    var result = await command.ExecuteScalarAsync();  // UNA SOLA VEZ
    entity.Id = Convert.ToInt32(result);
    return entity;
}

public async Task<Alumno?> GetByIdAsync(int id)
{
    var result = await _context.Alumnos
        .FromSqlRaw("EXEC sp_Alumnos_GetById @Id", new SqlParameter("@Id", id))
        .ToListAsync();  // NUNCA FirstOrDefaultAsync() sobre EXEC
    return result.FirstOrDefault();
}
```

### Service con Validaciones BR
```csharp
public async Task<ServiceResult<Alumno>> CreateAsync(Alumno alumno)
{
    if (string.IsNullOrWhiteSpace(alumno.Nombre)) return Fail("Nombre obligatorio");
    if (alumno.DNI < 1000000 || alumno.DNI > 99999999) return Fail("DNI 7-8 dígitos");
    if (alumno.FechaNacimiento == default) return Fail("Fecha nacimiento obligatoria");
    if (!_carreraRepository.ExistsAsync(alumno.CarreraId).Result) return Fail("Carrera no existe");
    if (await _repository.ExistsByDNIAsync(alumno.DNI)) return Fail("DNI duplicado");
    
    alumno.FechaInscripcion ??= DateTime.Now;
    return Ok(await _repository.CreateAsync(alumno));
}
```
